交互式技术课程

English

每一课都有小白和进阶两种讲解、可以亲手操作的动画，最后还有一个小测验。

第 1 课

一步步看懂 HTTP

跟着一个请求从 DNS 走到页面渲染完成，对着模拟 API 试遍每个 HTTP 方法，再做个小测验。
第 2 课

设计好用的 API

修复命名糟糕的端点，选出正确的状态码，看清游标分页为什么更好，并学会判断哪些变更会破坏客户端。
第 3 课

动手学 SQL

点一点就能拼出查询，看 JOIN 如何匹配行、GROUP BY 如何分组，并弄清一条查询真正的执行顺序。
第 4 课

设计数据库

弄坏一张“大表”再把它规范化，为关系建模，让全表扫描和索引赛跑，并在有无事务的情况下让一笔转账中途崩溃。
第 5 课

形式化验证

看看测试为什么会漏掉罕见的 bug，动手写规约，逐个状态地对加锁协议做模型检测，并用循环不变式证明循环正确。

开源项目拆解

从产品设计的角度读开源 AI 项目：为什么这样设计、做了哪些取舍、边界情况怎么处理。

拆解 1

Dify：AI 工作流如何真正落地

画布为什么这么设计，哪些环节用固定流程、哪些交给 agent，知识库、模型、工具怎么分层，原型怎么走向生产，以及 issue 里的真实痛点。
拆解 2

OpenAI Agents SDK：agent 该怎么设计

模型、指令、工具、交接、约束、观测为什么这样拆、怎么串起来，一张 agent 产品架构图，以及什么时候不该做成 agent。
拆解 3

autoresearch + nanochat：理解智能体式产品

从“人操作工具”到“人定义目标和评价函数、agent 自己循环”：目标、权限、环境、反馈指标和人工介入点该怎么设计。
