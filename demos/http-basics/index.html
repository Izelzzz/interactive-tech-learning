Unit 1

The request journey

The big picture. Opening a web page is like phoning a shop to order something:
  1. Look up the shop's phone number. (DNS)
  2. Dial and wait until someone picks up. (TCP)
  3. Check it's really that shop, then switch to a private line. (TLS)
  4. Say what you want. (HTTP request)
  5. The shop gets it ready. (server processing)
  6. They hand it over with a note saying "OK". (HTTP response)
  7. You unpack it, notice a few missing pieces and ask for those too. (render)
Under the hood. One page load goes through four protocol layers. Each layer relies on the one below it:
HTTPMethods, headers, status codes. HTTP/1.1 and h2 run over TLS + TCP; HTTP/3 runs over QUIC.
TLS 1.3Encryption and proof of the server's identity. Certificates, ECDHE, ALPN.
TCPA reliable, ordered stream of bytes. Replaced by QUIC (over UDP) in HTTP/3.
IPMoves packets to an address. DNS turns names into these addresses.
