# interactive-tech-learning

交互式技术学习平台。课程固定；单元可交互；小白 / 进阶双版本讲解。

产品规格见 `docs/`。

## Demos

所有课程入口：[`demos/index.html`](demos/index.html)。直接用浏览器打开即可，无需安装依赖。

- [`demos/http-basics/`](demos/http-basics/index.html)：HTTP 请求全过程与 HTTP 方法（动画讲解 + 交互练习 + 小测验，支持小白 / 进阶切换）。
- [`demos/api-design/`](demos/api-design/index.html)：如何设计好的 API：URL 命名、状态码与错误格式、分页（offset vs cursor 动画演示）、兼容性变更判断，以及小测验，支持小白 / 进阶切换。
